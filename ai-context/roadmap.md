# Roadmap (Phased Delivery)

MVP (8 hours hackathon focus):
- Authentication + RBAC
- Vehicle & Driver CRUD
- Trip creation, dispatch, complete, cancel (core validations)
- Basic dashboard KPIs and CSV export
- Local dev setup (SQLite) and minimal UI

Phase 2 (Post-MVP):
- Maintenance workflow and status automatic transitions
- Fuel & expense logging + simple cost aggregation
- Email reminders for license expiry
- File uploads for docs

Phase 3 (Polish & Scale):
- Rich analytics and ROI reports (background aggregation)
- Postgres migration & Prisma migrations
- Role-based UI refinements and audit logs
- E2E tests and CI/CD pipeline

Optional / Bonus:
- PDF export, advanced search, dark mode, multi-tenant support, mobile layout optimization
