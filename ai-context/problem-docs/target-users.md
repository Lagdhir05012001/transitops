# Target Users

- Fleet Manager: Oversees fleet assets, maintenance, lifecycle, and efficiency.
- Driver: Creates and completes trips; records odometer and fuel.
- Safety Officer: Tracks license validity, safety scores, and compliance.
- Financial Analyst: Reviews expenses, fuel consumption, and ROI.

## Responsibilities & Needs
- Role-based access and workflows tailored to each user persona.
- Notifications for expiring licenses and scheduled maintenance.
