# Dashboard

## KPIs
- Active Vehicles
- Available Vehicles
- Vehicles In Maintenance
- Active Trips
- Pending Trips
- Drivers On Duty
- Fleet Utilization (%)

## Features
- Filters by vehicle type, status, and region.
- Charts for utilization, fuel efficiency, and operational cost.
- CSV export for reports; PDF optional.
