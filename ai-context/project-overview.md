# Project Overview

TransitOps is a Smart Transport Operations Platform that centralizes vehicle, driver, dispatch, maintenance, and expense management to replace spreadsheets and manual logbooks.

Scope:
- Fleet Lifecycle: vehicle registration, status management, documents.
- Driver Management: license tracking, safety scores, availability.
- Trip Management: create, dispatch, complete, cancel workflows with validations.
- Maintenance & Fuel: maintenance logs, fuel/expense tracking, cost aggregation.
- Analytics & Reports: dashboard KPIs, CSV export, ROI calculations.

Primary stakeholders:
- Fleet Manager, Driver, Safety Officer, Financial Analyst.

Success criteria (MVP):
- Core CRUD for vehicles and drivers.
- Trip lifecycle with automatic status transitions and validations.
- Maintenance and fuel logging.
- Basic dashboard with key KPIs and CSV export.

See `api-spec.md` and `tech-stack.md` for implementation-level guidance.
